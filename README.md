# FlyRank AI — Portfolio Engineering & Workflow System

## Overview
This repository contains the architecture, core codebase, and deployment configurations for an interactive UI/UX portfolio and workflow automation system. Designed for software engineering and design evaluations, it integrates structured HTML5/CSS3 layouts with automated form handling via Netlify.

---

## System Architecture
1. **User Interface (Frontend):** Light-mode modern interface built with vanilla HTML5, CSS3, and JavaScript, optimized for fast loading and low latency.
2. **Form Infrastructure:** Integrated with Netlify Forms for backend response collection and serverless processing.
3. **Deployment Pipeline:** Continuous Deployment (CD) synced with the main branch on GitHub.
